पोस्ट लिखें और GitHub repository में सेव करें

1. GitHub से कनेक्ट करें

यह पैनल आपके ब्राउज़र से सीधे GitHub API इस्तेमाल करता है। Token केवल इस खुले पेज की memory में रहता है; इसे code या browser storage में सेव नहीं किया जाता। काम पूरा होने पर Disconnect करें।

अभी GitHub से कनेक्ट नहीं है।

ज़रूरी सुरक्षा

Token बनाते समय केवल इसी repository की access दें और Contents: Read and write permission चुनें। Token को किसी से साझा न करें। यह सार्वजनिक साइट है, इसलिए कभी भी token को HTML file में न लिखें।

2. पोस्ट मैनेज करें 0 पोस्ट

यह शुरुआती पैनल पोस्ट को repository के root में posts.json में सेव करता है। आपकी मौजूदा homepage को इस फ़ाइल से पोस्ट दिखाने के लिए अलग से जोड़ना पड़ सकता है।

पहले GitHub से कनेक्ट करें।

नई पोस्ट लिखें

Save करने पर GitHub repository में commit बनेगा। इससे वेबसाइट पर पोस्ट तभी दिखेगी जब homepage या post template इस posts.json को पढ़ता हो।
